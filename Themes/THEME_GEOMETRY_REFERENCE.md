# PrettyFrames measured geometry reference

> Generated by `node tools/GenerateThemeGeometryReference.js`. Do not edit measured tables by hand.

This worksheet compares implemented themes as measured examples. It is not a coordinate preset. A future independent theme should create its own composition, then use the same measurements to verify that live widgets align with its art.

## Reading the measurements

- Display rectangles use a top-left origin: positive X moves right and positive Y moves down.
- Source rectangles are the display rectangles mapped through the configured UV crop into TGA pixels.
- `visible alpha` is the percentage of mapped source pixels with alpha greater than 8/255. Low coverage is normally desirable for portrait and bar openings; portrait rims and indicator decorations may intentionally overlap the edges of their widget rectangles, so the number is diagnostic rather than a pass/fail threshold.
- `mean alpha` includes partial transparency. The nameplate health backing is intentionally expected to be opaque.
- Measurements describe the canonical portrait-left orientation. Mirrored geometry follows the reflection rules in the authoring guide.
- Text spans do not claim a rectangle height because fonts and metrics remain shared runtime values.
